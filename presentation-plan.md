- Mainframe developers (COBOL, JCL, DB2, CICS, etc.)

## Approach
- Each file is a self-contained detailed topic (5-10 min presentation)
- Written for AI beginners with mainframe background
- Bob-specific features focused on COBOL/JCL/mainframe use cases
- No mention of other AI chat assistant tools — only IBM Bob
- Simple analogies using mainframe concepts they already know
